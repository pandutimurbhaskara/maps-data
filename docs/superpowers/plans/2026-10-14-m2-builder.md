# M2: Builder (editor, styling, widgets, SQL parameters) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A map editor at `/builder/:id` where a user adds OSM sources, styles vector and H3 layers, adds viewport-aware widgets that cross-filter, and binds SQL parameters to controls. Everything autosaves, and the viewer shows the same map read-only.

**Architecture:**
- **Server (Go):** gains the CARTO-compatible `/v3/stats` and `/v3/sql/{conn}/model/*` endpoints, spatial filters, a resources (table catalog) endpoint and a place geocoder.
- **Web:** stops hand-mapping layers. Map documents now go through `@carto/api-client`'s `_fillInMapDatasets` → `_fillInTileStats` → `parseMap`, and then `@deck.gl/carto`'s `LayerFactory`. That way CARTO's own MIT code interprets styling, and widgets use each dataset's `widgetSource`.
- **Builder state:** one reducer with derived fields (compiled SQL, H3 `aggregationExp`) and a debounced autosave.

**Tech Stack:**
- Server: Go 1.26, duckdb-go v2 (DuckDB 1.5.6).
- Web: Vite 8, React 19, TS 7, Vitest 5, deck.gl 9.3.11, `@carto/api-client` 0.5.34, `cartocolor` 5.0.2, maplibre-gl 6.

**Spec:** `docs/superpowers/specs/2026-10-14-m2-builder-design.md`. Its parent is `docs/superpowers/specs/2026-10-14-osm-duckdb-maps-design.md`, and the evidence is in `docs/re/2026-10-14-carto-maps-findings-ledger.md`.

## Global Constraints

- All M1 constraints still hold. The ones that matter most here:
  - The data DB is opened READ_ONLY and sandboxed.
  - User SQL goes through `sqlguard.ValidateSelect`, which also denies `duckdb_*`, `pragma_*` and `current_setting`.
  - Internal named args use the `p__` prefix.
  - MVT layer name is `default`.
  - No CARTO code, strings or assets are copied.
  - Commits use Conventional Commits with these types only: `feat fix docs refactor test perf chore ci`. No AI trailers.
- Dataset documents use CARTO's format (spec D2): `geoColumn` is `"geom"` or `"h3:<col>"`. There is no `spatialIndex` field.
- Rendering goes only through `prepareMap()` (`_fillInMapDatasets` + `_fillInTileStats` + `parseMap`) and `toDeckLayers()` (`LayerFactory` with `loaders: [MVTLoader]` on `tileset` layers and `loadOptions.worker = false` on all layers).
- Model API operations are `count | avg | min | max | sum | custom`. A `custom` `operationExp` must pass `ValidateSelect("SELECT " + exp)`.
- Model responses use the shapes in spec D3 exactly, with lowercase keys.
- SQL-parameter `sqlName`s must match `^[A-Za-z][A-Za-z0-9_]*$` and must not start with `p__`.
- Widgets refresh at most once per 300 ms of viewport change. Autosave fires 800 ms after the last edit.
- `cartocolor` palettes are CC-BY-4.0, so the builder's palette picker shows the credit "Colors: CARTOColors (CC BY 4.0)".

## Review Focus

1. **Category widget with only one category left after cross-filtering.** The widget that owns the filter must still show all categories, because its own filter is excluded via `filterOwner`, while the other widgets and the map narrow. Tests in Tasks 7 and 14.
2. **H3 layer coloured by an aggregate when the source has zero rows in the viewport.** Expect no crash, a neutral colour, and the legend shows "No data". Tests in Tasks 10 and 16.
3. **A Category SQL parameter with every value deselected.** Expect the map and widgets to show nothing, not an SQL error (an empty `IN` list). Tests in Tasks 9 and 15.
4. **Editing quickly while a save is in flight.** Expect no lost edit: a change made during a save is saved by the next debounce, and save responses never overwrite newer local state. Test in Task 11.
5. **Column names with spaces or quotes coming from a custom SQL source.** Expect the server to quote them everywhere (stats, model API, MVT); the UI may still offer them as fields. Tests in Tasks 2 and 3.

```go
// spatialClause keeps rows whose geometry (geo) or cell centre (h3) intersects SpatialFilter.
func (s Source) spatialClause() (string, []any, error) {
	if len(s.SpatialFilter) == 0 || string(s.SpatialFilter) == "null" {
		return "", nil, nil
	}
	var g struct {
		Type string `json:"type"`
	}
	if err := json.Unmarshal(s.SpatialFilter, &g); err != nil || g.Type == "" {
		return "", nil, fmt.Errorf("%w: spatial filter must be a GeoJSON geometry", ErrBadRequest)
	}
	col, err := Ident(s.SpatialColumnName())
	if err != nil {
		return "", nil, err
	}
	target := col
	if s.SpatialDataType == H3 {
		target = "ST_Point(h3_cell_to_lng(" + col + "), h3_cell_to_lat(" + col + "))"
	}
	arg := sql.Named(InternalParamPrefix+"sf", string(s.SpatialFilter))
	return "ST_Intersects(" + target + ", ST_GeomFromGeoJSON($" + InternalParamPrefix + "sf))", []any{arg}, nil
}
```

```go
package describe

import (
	"context"
	"database/sql"
	"fmt"
	"strconv"
	"strings"
)

// AttrStats is the /v3/stats response for one attribute (spec M2 D3).
type AttrStats struct {
	Attribute  string               `json:"attribute"`
	Type       string               `json:"type"`
	Min        *float64             `json:"min,omitempty"`
	Max        *float64             `json:"max,omitempty"`
	Avg        *float64             `json:"avg,omitempty"`
	Sum        *float64             `json:"sum,omitempty"`
	Quantiles  map[string][]float64 `json:"quantiles,omitempty"`
	Categories []Category           `json:"categories,omitempty"`
}

const minQuantiles, maxQuantiles = 2, 10

// Attribute computes stats for one column: min/max/avg/sum/quantiles for numbers, top categories otherwise.
func Attribute(ctx context.Context, db *sql.DB, rel string, args []any, col Column, maxCategories int) (AttrStats, error) {
	out := AttrStats{Attribute: col.Name, Type: statsType(col.Type)}
	if col.Type != "number" {
		cats, err := topCategories(ctx, db, rel, col.Name, args, maxCategories)
		out.Categories = cats
		return out, err
	}
	x := "CAST(" + quote(col.Name) + " AS DOUBLE)"
	sel := []string{"min(" + x + ")", "max(" + x + ")", "avg(" + x + ")", "sum(" + x + ")"}
	for n := minQuantiles; n <= maxQuantiles; n++ {
		fracs := make([]string, n+1)
		for i := 0; i <= n; i++ {
			fracs[i] = strconv.FormatFloat(float64(i)/float64(n), 'f', -1, 64)
		}
		sel = append(sel, "quantile_cont("+x+", ["+strings.Join(fracs, ", ")+"])")
	}
	vals := make([]sql.NullFloat64, 4)
	lists := make([]any, maxQuantiles-minQuantiles+1)
	dest := []any{&vals[0], &vals[1], &vals[2], &vals[3]}
	for i := range lists {
		dest = append(dest, &lists[i])
	}
	q := "SELECT " + strings.Join(sel, ", ") + " FROM " + rel + " AS _r"
	if err := db.QueryRowContext(ctx, q, args...).Scan(dest...); err != nil {
		return out, err
	}
	ptr := func(v sql.NullFloat64) *float64 {
		if !v.Valid {
			return nil
		}
		f := v.Float64
		return &f
	}
	out.Min, out.Max, out.Avg, out.Sum = ptr(vals[0]), ptr(vals[1]), ptr(vals[2]), ptr(vals[3])
	if out.Min == nil {
		return out, nil // no non-null values
	}
	out.Quantiles = map[string][]float64{}
	for i, l := range lists {
		items, ok := l.([]any)
		if !ok {
			return out, fmt.Errorf("describe: quantiles scanned as %T", l)
		}
		qs := make([]float64, len(items))
		for j, it := range items {
			f, ok := it.(float64)
			if !ok {
				return out, fmt.Errorf("describe: quantile value %T", it)
			}
			qs[j] = f
		}
		out.Quantiles[strconv.Itoa(minQuantiles+i)] = qs
	}
	return out, nil
}

func topCategories(ctx context.Context, db *sql.DB, rel, col string, args []any, limit int) ([]Category, error) {
	if limit <= 0 {
		limit = 20
	}
	q := quote(col)
	rows, err := db.QueryContext(ctx, fmt.Sprintf("SELECT CAST(%s AS VARCHAR) AS c, count(*) AS n FROM %s AS _r WHERE %s IS NOT NULL GROUP BY 1 ORDER BY 2 DESC, 1 LIMIT %d", q, rel, q, limit), args...)
	if err != nil {
		return nil, err
	}
	defer rows.Close()
	var out []Category
	for rows.Next() {
		var c Category
		if err := rows.Scan(&c.Category, &c.Frequency); err != nil {
			return nil, err
		}
		out = append(out, c)
	}
	return out, rows.Err()
}
```

```go
package mapsapi

import (
	"context"
	"database/sql"
	"errors"
	"log"
	"net/http"

	"osm-maps/server/internal/describe"
	"osm-maps/server/internal/httpx"
	"osm-maps/server/internal/source"
	"osm-maps/server/internal/sqlguard"
	"osm-maps/server/internal/tiles"
)

// Resolve validates user SQL, compiles the source relation and reads its schema.
// Shared by the maps, stats and model endpoints.
func Resolve(ctx context.Context, db *sql.DB, src source.Source) (string, []any, []describe.Column, error) {
	if src.Type == source.TypeQuery {
		if err := sqlguard.ValidateSelect(ctx, db, src.Query); err != nil {
			return "", nil, nil, err
		}
	}
	if src.AggregationExp != "" {
		if err := sqlguard.ValidateSelect(ctx, db, "SELECT "+src.AggregationExp); err != nil {
			return "", nil, nil, err
		}
	}
	rel, args, err := src.Relation()
	if err != nil {
		return "", nil, nil, err
	}
	schema, err := describe.Schema(ctx, db, rel, args)
	if err != nil {
		return "", nil, nil, QueryError(err)
	}
	return rel, args, schema, nil
}

// QueryError is the exported form of queryError (first line only, paths redacted).
func QueryError(err error) error { return queryError(err) }

// Fail writes err with the status the Data API uses for it.
func Fail(ctx context.Context, w http.ResponseWriter, err error) {
	switch {
	case ctx.Err() != nil:
		httpx.WriteError(w, http.StatusRequestTimeout, "query timed out")
	case errors.Is(err, source.ErrBadRequest), errors.Is(err, sqlguard.ErrNotSelect),
		errors.Is(err, errQuery), errors.Is(err, tiles.ErrTooLarge):
		httpx.WriteError(w, http.StatusBadRequest, err.Error())
	default:
		log.Printf("mapsapi: %v", err)
		httpx.WriteError(w, http.StatusInternalServerError, "internal error")
	}
}
```

```go
// handleStats serves /v3/stats/{conn}/{attr} (query sources, q=) and /v3/stats/{conn}/{table}/{attr}.
// Only source columns are consulted; the spatial column is not required (tilestats for any layer).
```

```go
package modelapi

import (
	"context"
	"fmt"
	"strconv"
	"time"
)

// jsonValue converts a DuckDB scan value into something encoding/json writes sensibly.
func jsonValue(v any) any {
	switch x := v.(type) {
	case nil, bool, string, float64, float32, int, int8, int16, int32, int64, uint8, uint16, uint32, uint64:
		return x
	case []byte:
		return nil // blobs (raw geometry) are not JSON values
	case time.Time:
		return x.UTC().Format(time.RFC3339Nano)
	case interface{ Float64() float64 }: // duckdb.Decimal
		return x.Float64()
	case fmt.Stringer: // *big.Int (HUGEINT), UUID, …
		if f, err := strconv.ParseFloat(x.String(), 64); err == nil {
			return f
		}
		return x.String()
	case []any:
		out := make([]any, len(x))
		for i := range x {
			out[i] = jsonValue(x[i])
		}
		return out
	}
	return fmt.Sprint(v)
}

func toFloat(v any) float64 {
	switch x := jsonValue(v).(type) {
	case float64:
		return x
	case float32:
		return float64(x)
	case int64:
		return float64(x)
	case int32:
		return float64(x)
	case int:
		return float64(x)
	case uint64:
		return float64(x)
	case uint32:
		return float64(x)
	}
	return 0
}

// rows runs sqlText with the source args and returns every row as a column→value map.
func (q query) rows(ctx context.Context, sqlText string) ([]map[string]any, error) {
	rs, err := q.db.QueryContext(ctx, sqlText, q.args...)
	if err != nil {
		return nil, err
	}
	defer rs.Close()
	cols, err := rs.Columns()
	if err != nil {
		return nil, err
	}
	out := []map[string]any{}
	vals := make([]any, len(cols))
	ptrs := make([]any, len(cols))
	for i := range vals {
		ptrs[i] = &vals[i]
	}
	for rs.Next() {
		if err := rs.Scan(ptrs...); err != nil {
			return nil, err
		}
		m := make(map[string]any, len(cols))
		for i, c := range cols {
			m[c] = jsonValue(vals[i])
		}
		out = append(out, m)
	}
	return out, rs.Err()
}
```

```go
func bad(format string, a ...any) error {
	return fmt.Errorf("%w: "+format, append([]any{source.ErrBadRequest}, a...)...)
}

func quote(name string) string { return `"` + strings.ReplaceAll(name, `"`, `""`) + `"` }

func (q query) column(name string) (string, describe.Column, error) {
	c, ok := q.cols[name]
	if !ok {
		return "", c, bad("unknown column %q", name)
	}
	return quote(name), c, nil
}

// aggregate returns the SQL aggregate for a widget operation over column (spec M2 D3).
func (q query) aggregate(ctx context.Context, op, column, exp string) (string, error) {
	switch op {
	case "", "count":
		if column == "" || column == "*" {
			return "count(*)", nil
		}
		c, _, err := q.column(column)
		return "count(" + c + ")", err
	case "avg", "min", "max", "sum":
		c, _, err := q.column(column)
		if err != nil {
			return "", err
		}
		return op + "(CAST(" + c + " AS DOUBLE))", nil
	case "custom":
		if strings.TrimSpace(exp) == "" {
			return "", bad("operationExp is required for custom operation")
		}
		if err := sqlguard.ValidateSelect(ctx, q.db, "SELECT "+exp); err != nil {
			return "", err
		}
		return "(" + exp + ")", nil
	}
	return "", bad("unsupported operation %q", op)
}

func formula(ctx context.Context, q query, p params) (any, error) {
	agg, err := q.aggregate(ctx, p.Operation, p.columnName(), p.OperationExp)
	if err != nil {
		return nil, err
	}
	rows, err := q.rows(ctx, "SELECT "+agg+" AS value FROM "+q.rel+" AS _r")
	return map[string]any{"rows": rows}, err
}

func rangeModel(ctx context.Context, q query, p params) (any, error) {
	c, _, err := q.column(p.columnName())
	if err != nil {
		return nil, err
	}
	x := "CAST(" + c + " AS DOUBLE)"
	rows, err := q.rows(ctx, "SELECT min("+x+") AS min, max("+x+") AS max FROM "+q.rel+" AS _r")
	return map[string]any{"rows": rows}, err
}

func category(ctx context.Context, q query, p params) (any, error) {
	col := p.columnName()
	c, _, err := q.column(col)
	if err != nil {
		return nil, err
	}
	opCol := p.OperationColumn
	if opCol == "" || p.Operation == "" || p.Operation == "count" {
		opCol = "*" // count rows per category, not non-null values of the column
	}
	agg, err := q.aggregate(ctx, p.Operation, opCol, p.OperationExp)
	if err != nil {
		return nil, err
	}
	order := map[string]string{
		"":                  "value DESC NULLS LAST, name",
		"frequency_desc":    "value DESC NULLS LAST, name",
		"frequency_asc":     "value ASC NULLS LAST, name",
		"alphabetical_asc":  "name ASC NULLS LAST",
		"alphabetical_desc": "name DESC NULLS LAST",
	}[p.OrderBy]
	if order == "" {
		return nil, bad("unsupported orderBy %q", p.OrderBy)
	}
	rows, err := q.rows(ctx, "SELECT CAST("+c+" AS VARCHAR) AS name, "+agg+" AS value FROM "+q.rel+" AS _r GROUP BY 1 ORDER BY "+order)
	if err != nil {
		return nil, err
	}
	meta := map[string]any{}

				others += toFloat(r["value"])
			}
			rows = rows[:p.OthersThreshold]
		}
		meta["others"] = others
	}
	return map[string]any{"rows": rows, "metadata": meta}, nil
```

```go
// Package modelapi serves CARTO's SQL "model" API used by widgets (/v3/sql/{conn}/model/{model}).
package modelapi

import (
	"context"
	"database/sql"
	"encoding/json"
	"errors"
	"net/http"
	"time"

	"osm-maps/server/internal/describe"
	"osm-maps/server/internal/httpx"
	"osm-maps/server/internal/mapsapi"
	"osm-maps/server/internal/source"
	"osm-maps/server/internal/sqlguard"
)

type Server struct {
	Conns        map[string]*sql.DB
	QueryTimeout time.Duration
}

func (s *Server) Register(mux *http.ServeMux) {
	mux.HandleFunc("GET /v3/sql/{conn}/model/{model}", s.handle)
	mux.HandleFunc("POST /v3/sql/{conn}/model/{model}", s.handle)
}

func (s *Server) handle(w http.ResponseWriter, r *http.Request) {
	timeout := s.QueryTimeout
	if timeout <= 0 {
		timeout = 15 * time.Second
	}
	ctx, cancel := context.WithTimeout(r.Context(), timeout)
	defer cancel()
	db, ok := s.Conns[r.PathValue("conn")]
	if !ok {
		httpx.WriteError(w, http.StatusNotFound, "connection not found")
		return
	}
	model, ok := models[r.PathValue("model")]
	if !ok {
		mapsapi.Fail(ctx, w, bad("unsupported model %q", r.PathValue("model")))
		return
	}
	v, err := mapsapi.ParseParams(r)
	if err != nil {
		mapsapi.Fail(ctx, w, err)
		return
	}
	typ := v.Get("type")
	if typ == "table" {
		v.Set("name", v.Get("source"))
	} else {
		v.Set("q", v.Get("source"))
	}
	src, err := mapsapi.SourceFrom(typ, v)
	if err != nil {
		mapsapi.Fail(ctx, w, err)
		return
	}
	var p params
	if raw := v.Get("params"); raw != "" {
		if err := json.Unmarshal([]byte(raw), &p); err != nil {
			mapsapi.Fail(ctx, w, bad("params must be a JSON object: %v", err))
			return
		}
	}
	rel, args, schema, err := mapsapi.Resolve(ctx, db, src)
	if err != nil {
		mapsapi.Fail(ctx, w, err)
		return
	}
	cols := make(map[string]describe.Column, len(schema))
	for _, c := range schema {
		cols[c.Name] = c
	}
	res, err := model(ctx, query{db: db, rel: rel, args: args, cols: cols}, p)
	if err != nil {
		if !errors.Is(err, source.ErrBadRequest) && !errors.Is(err, sqlguard.ErrNotSelect) && ctx.Err() == nil {
			err = mapsapi.QueryError(err)
		}
		mapsapi.Fail(ctx, w, err)
		return
	}
	httpx.WriteJSON(w, http.StatusOK, res)
}
```

```go
func histogram(ctx context.Context, q query, p params) (any, error) {
	c, _, err := q.column(p.columnName())
	if err != nil {
		return nil, err
	}
	if len(p.Ticks) == 0 {
		return nil, bad("histogram needs at least one tick")
	}
	cases := "CASE"
	for i, t := range p.Ticks {
		if math.IsNaN(t) || math.IsInf(t, 0) || (i > 0 && t <= p.Ticks[i-1]) {
			return nil, bad("ticks must be finite and strictly increasing")
		}
		cases += " WHEN __x < " + strconv.FormatFloat(t, 'g', -1, 64) + " THEN " + strconv.Itoa(i)
	}
	cases += " ELSE " + strconv.Itoa(len(p.Ticks)) + " END"
	agg, err := q.aggregate(ctx, p.Operation, p.columnName(), p.OperationExp)
	if err != nil {
		return nil, err
	}
	rows, err := q.rows(ctx, fmt.Sprintf(
		"SELECT %s AS tick, %s AS value FROM (SELECT *, CAST(%s AS DOUBLE) AS __x FROM %s AS _r) AS _h WHERE __x IS NOT NULL GROUP BY 1 ORDER BY 1",
		cases, agg, c, q.rel))
	return map[string]any{"rows": rows}, err
}

func table(ctx context.Context, q query, p params) (any, error) {
	names := p.columnList()
	if len(names) == 0 {
		return nil, bad("table needs columns")
	}
	sel := make([]string, len(names))
	for i, n := range names {
		c, col, err := q.column(n)
		if err != nil {
			return nil, err
		}
		if col.Type == "geometry" {
			sel[i] = "ST_AsText(" + c + ") AS " + c
		} else {
			sel[i] = c
		}
	}
	order := ""
	if p.SortBy != "" {
		c, _, err := q.column(p.SortBy)
		if err != nil {
			return nil, err
		}
		dir := "ASC"
		switch strings.ToLower(p.SortDirection) {
		case "", "asc":
		case "desc":
			dir = "DESC"
		default:
			return nil, bad("sortDirection must be asc or desc")
		}
		order = " ORDER BY " + c + " " + dir + " NULLS LAST"
	}
	limit := p.Limit
	if limit == 0 {
		limit = 10
	}
	if limit < 1 || limit > 1000 || p.Offset < 0 {
		return nil, bad("limit must be 1..1000 and offset >= 0")
	}
	rows, err := q.rows(ctx, fmt.Sprintf("SELECT %s FROM %s AS _r%s LIMIT %d OFFSET %d", strings.Join(sel, ", "), q.rel, order, limit, p.Offset))
	if err != nil {
		return nil, err
	}
	total, err := q.rows(ctx, "SELECT count(*) AS total FROM "+q.rel+" AS _r")
	if err != nil {
		return nil, err
	}
	return map[string]any{"rows": rows, "metadata": map[string]any{"total": total[0]["total"]}}, nil
}

var stepUnits = map[string]bool{"year": true, "month": true, "week": true, "day": true, "hour": true, "minute": true, "second": true}

func timeseries(ctx context.Context, q query, p params) (any, error) {
	if p.SplitByCategory != "" {
		return nil, bad("splitByCategory is not supported yet")
	}
	col := p.columnName()
	c, _, err := q.column(col)
	if err != nil {
		return nil, err
	}
	if !stepUnits[p.StepSize] {
		return nil, bad("unsupported stepSize %q", p.StepSize)
	}
	mult := p.StepMultiplier
	if mult == 0 {
		mult = 1
	}
	if mult < 1 || mult > 1000 {
		return nil, bad("stepMultiplier must be 1..1000")
	}
	opCol := p.OperationColumn
	if opCol == "" || p.Operation == "" || p.Operation == "count" {
		opCol = "*"
	}
	agg, err := q.aggregate(ctx, p.Operation, opCol, p.OperationExp)
	if err != nil {
		return nil, err
	}
	rows, err := q.rows(ctx, fmt.Sprintf(
		"SELECT epoch_ms(time_bucket(INTERVAL '%d %s', CAST(%s AS TIMESTAMP))) AS name, %s AS value FROM %s AS _r WHERE %s IS NOT NULL GROUP BY 1 ORDER BY 1",
		mult, p.StepSize, c, agg, q.rel, c))
	return map[string]any{"rows": rows, "metadata": map[string]any{"categories": nil}}, err
}
```

```go
// Package catalog lists the spatial tables a connection exposes to the builder.
package catalog

import (
	"context"
	"database/sql"
	"strings"

	"osm-maps/server/internal/describe"
)

type Resource struct {
	Name      string            `json:"name"`
	Columns   []describe.Column `json:"columns"`
	GeoColumn string            `json:"geoColumn"`          // geometry column, or "h3:<col>" (CARTO dataset convention)
	H3Column  string            `json:"h3Column,omitempty"` // H3 column usable for aggregation
}

// h3Names mirrors CARTO's spatial-index column aliases (ledger: spatial index detection).
var h3Names = map[string]bool{"h3": true, "hex": true, "h3id": true, "hex_id": true, "h3hex": true}

// List returns every table in the main schema that has a geometry or H3 column, in name order.
// Server-internal catalog query: not user SQL, so it does not pass through sqlguard.
func List(ctx context.Context, db *sql.DB) ([]Resource, error) {
	rows, err := db.QueryContext(ctx, `SELECT table_name, column_name, data_type FROM duckdb_columns()
WHERE database_name = current_database() AND schema_name = 'main' AND NOT internal
ORDER BY table_name, column_index`)
	if err != nil {
		return nil, err
	}
	defer rows.Close()
	var (
		out []Resource
		cur *Resource
	)
	for rows.Next() {
		var table, col, typ string
		if err := rows.Scan(&table, &col, &typ); err != nil {
			return nil, err
		}
		if cur == nil || cur.Name != table {
			out = append(out, Resource{Name: table})
			cur = &out[len(out)-1]
		}
		cur.Columns = append(cur.Columns, describe.Column{Name: col, Type: describe.Kind(typ)})
		upper := strings.ToUpper(typ)
		if upper == "GEOMETRY" && cur.GeoColumn == "" {
			cur.GeoColumn = col
		}
		if cur.H3Column == "" && h3Names[strings.ToLower(col)] && (upper == "UBIGINT" || upper == "BIGINT" || upper == "VARCHAR") {
			cur.H3Column = col
		}
	}
	if err := rows.Err(); err != nil {
		return nil, err
	}
	spatial := out[:0]
	for _, r := range out {
		if r.GeoColumn == "" && r.H3Column != "" {
			r.GeoColumn = "h3:" + r.H3Column
		}
		if r.GeoColumn != "" {
			spatial = append(spatial, r)
		}
	}
	return spatial, nil
}
```

```go
// Package geocode searches place names in the OSM data (spec M2 D7: ranked substring, not FTS).
package geocode

import (
	"context"
	"database/sql"
	"fmt"
	"net/http"
	"strconv"
	"strings"

	"osm-maps/server/internal/httpx"
)

type Place struct {
	Name      string  `json:"name"`
	Kind      string  `json:"kind"`
	Longitude float64 `json:"longitude"`
	Latitude  float64 `json:"latitude"`
}

// candidates are searched when the table exists; kind and point are SQL expressions over that table.
var candidates = []struct{ table, kind, point string }{
	{"osm_points", "coalesce(amenity, shop, tourism, 'place')", "geom"},
	{"osm_polygons", "coalesce(building, landuse, leisure, 'area')", "ST_Centroid(geom)"},
	{"demo_points", "category", "geom"},
}

func Search(ctx context.Context, db *sql.DB, text string, limit int) ([]Place, error) {
	existing := map[string]bool{}
	rows, err := db.QueryContext(ctx, `SELECT table_name FROM duckdb_tables() WHERE database_name = current_database() AND schema_name = 'main'`)
	if err != nil {
		return nil, err
	}
	for rows.Next() {
		var n string
		if err := rows.Scan(&n); err != nil {
			rows.Close()
			return nil, err
		}
		existing[n] = true
	}
	rows.Close()

	var parts []string
	for _, c := range candidates {
		if existing[c.table] {
			parts = append(parts, fmt.Sprintf(
				`SELECT name, CAST(%s AS VARCHAR) AS kind, ST_X(%s) AS lon, ST_Y(%s) AS lat FROM %s WHERE name IS NOT NULL AND contains(lower(name), lower($q))`,
				c.kind, c.point, c.point, c.table))
		}
	}
	out := []Place{}
	if len(parts) == 0 {
		return out, nil
	}
	q := `SELECT name, kind, lon, lat FROM (` + strings.Join(parts, " UNION ALL ") + `) AS _p
ORDER BY CASE WHEN lower(name) = lower($q) THEN 0 WHEN starts_with(lower(name), lower($q)) THEN 1 ELSE 2 END, length(name), name
LIMIT ` + strconv.Itoa(limit)
	rs, err := db.QueryContext(ctx, q, sql.Named("q", text))
	if err != nil {
		return nil, err
	}
	defer rs.Close()
	for rs.Next() {
		var p Place
		var kind sql.NullString
		if err := rs.Scan(&p.Name, &kind, &p.Longitude, &p.Latitude); err != nil {
			return nil, err
		}
		p.Kind = kind.String
		out = append(out, p)
	}
	return out, rs.Err()
}

type Handler struct{ DB *sql.DB }

func (h *Handler) Register(mux *http.ServeMux) {
	mux.HandleFunc("GET /v3/lds/geocoding/geocode", h.geocode)
}

func (h *Handler) geocode(w http.ResponseWriter, r *http.Request) {
	text := strings.TrimSpace(r.URL.Query().Get("address"))
	if text == "" || len(text) > 200 {
		httpx.WriteError(w, http.StatusBadRequest, "address must be 1..200 characters")
		return
	}
	limit := 5
	if l := r.URL.Query().Get("limit"); l != "" {
		n, err := strconv.Atoi(l)
		if err != nil || n < 1 || n > 20 {
			httpx.WriteError(w, http.StatusBadRequest, "limit must be 1..20")
			return
		}
		limit = n
	}
	places, err := Search(r.Context(), h.DB, text, limit)
	if err != nil {
		httpx.WriteError(w, http.StatusInternalServerError, "geocoding failed")
		return
	}
	httpx.WriteJSON(w, http.StatusOK, map[string]any{"rows": places})
}
```

```ts
import { _fillInMapDatasets, _fillInTileStats, parseMap, type WidgetSource } from '@carto/api-client';
import type { DatasetDoc, MapDoc } from '../lib/mapDoc';

export interface RenderContext {
  apiBaseUrl: string;
  accessToken: string;
}

export type LoadedDataset = DatasetDoc & {
  data: { tiles: string[]; widgetSource: WidgetSource; maxresolution?: number; schema?: { name: string; type: string }[] };
};

export interface PreparedMap {
  parsed: ReturnType<typeof parseMap>;
  datasets: LoadedDataset[];
  errors: Record<string, string>;
}

type FillContext = Parameters<typeof _fillInMapDatasets>[1];

// prepareMap runs CARTO's own map pipeline (spec M2 D1): sources → tilestats → parseMap.
// A dataset that fails to load (bad SQL, unknown column) is reported in `errors` and its layers are dropped,
// instead of failing the whole map.
export async function prepareMap(doc: MapDoc, datasets: DatasetDoc[], ctx: RenderContext): Promise<PreparedMap> {
  const keplerMapConfig = structuredClone(doc.keplerMapConfig);
  const copies = structuredClone(datasets) as LoadedDataset[];
  const errors: Record<string, string> = {};
  const fill = ctx as unknown as FillContext;
  await Promise.all(
    copies.map(async (d) => {
      try {
        await _fillInMapDatasets({ datasets: [d], keplerMapConfig } as never, fill);
      } catch (e) {
        errors[d.id] = (e as Error).message;
      }
    }),
  );
  const loaded = copies.filter((d) => !errors[d.id]);
  const json = {
    ...doc,
    keplerMapConfig: {
      ...keplerMapConfig,
      config: {
        ...keplerMapConfig.config,
        visState: {
          ...keplerMapConfig.config.visState,
          layers: keplerMapConfig.config.visState.layers.filter((l) => !errors[l.config.dataId]),
        },
      },
    },
    datasets: loaded,
  };
  try {
    await _fillInTileStats(json as never, fill);
  } catch (e) {
    // a stats failure must not hide the map; parseMap falls back to tilestats from the TileJSON
    errors.__stats = (e as Error).message;
  }
  return { parsed: parseMap(json), datasets: loaded, errors };
}
```

```ts
import type { SqlParameter } from './mapDoc';

export class CompileError extends Error {}

const NAME = /^[A-Za-z][A-Za-z0-9_]*$/;
const PLACEHOLDER = /{{\s*([^}]*?)\s*}}/g;

type Binding = { kind: 'list' | 'scalar' | 'date'; value: unknown };

function bindings(params: SqlParameter[]): Map<string, Binding> {
  const out = new Map<string, Binding>();
  const add = (sqlName: string, b: Binding) => {
    if (!NAME.test(sqlName) || sqlName.startsWith('p__')) throw new CompileError(`invalid parameter name "${sqlName}"`);
    out.set(sqlName, b);
  };
  for (const p of params) {
    switch (p.type) {
      case 'Category':
        add(p.item.sqlName, { kind: 'list', value: p.item.value });
        break;
      case 'Numeric':
        add(p.item.sqlName, { kind: 'scalar', value: p.item.value });
        break;
      case 'NumericRange':
        add(p.start.sqlName, { kind: 'scalar', value: p.start.value });
        add(p.end.sqlName, { kind: 'scalar', value: p.end.value });
        break;
      case 'DateRange':
        add(p.start.sqlName, { kind: 'date', value: p.start.value });
        add(p.end.sqlName, { kind: 'date', value: p.end.value });
        break;
    }
  }
  return out;
}

export function placeholders(template: string): string[] {
  return [...new Set([...template.matchAll(PLACEHOLDER)].map((m) => m[1]))];
}

// compileQuery turns a {{name}} query template into DuckDB SQL with named parameters (spec M2 D5).
export function compileQuery(template: string, params: SqlParameter[]): { source: string; queryParameters: Record<string, unknown> | null } {
  const b = bindings(params);
  const used: Record<string, unknown> = {};
  const source = template.replace(PLACEHOLDER, (_m, name: string) => {
    const binding = b.get(name);
    if (!binding) throw new CompileError(`unknown parameter {{${name}}}`);
    used[name] = binding.value;
    if (binding.kind === 'list') return `(SELECT unnest(CAST(CAST($${name} AS JSON) AS VARCHAR[])))`;
    if (binding.kind === 'date') return `CAST($${name} AS DATE)`;
    return `$${name}`;
  });
  return { source, queryParameters: Object.keys(used).length ? used : null };
}
```

```ts
import { compileCustomAggregation } from '@carto/api-client';
import { colorRange } from './defaults';
import type { LayerDoc, Operation, ScaleType } from './mapDoc';

export const quoteIdent = (name: string) => `"${name.replaceAll('"', '""')}"`;

export function h3Expression(op: Operation, column?: string): string {
  if (op === 'count') return 'count(*)';
  if (!column) throw new Error(`${op} needs a column`);
  return `${op}(${quoteIdent(column)})`;
}

// The alias parseMap derives for a custom aggregation; the server must return the value under this name.
export const aggregationAlias = (exp: string) => compileCustomAggregation(exp, {} as never);

// buildAggregationExp is the dataset's aggregationExp for its H3 layers (spec M2 D6).
export function buildAggregationExp(datasetId: string, layers: LayerDoc[]): string {
  const parts = ['1 AS __aggregationValue'];
  const seen = new Set<string>();
  for (const l of layers) {
    const v = l.config.visConfig;
    if (l.type !== 'h3' || l.config.dataId !== datasetId || v.colorAggregation !== 'custom' || !v.colorAggregationExp) continue;
    const alias = aggregationAlias(v.colorAggregationExp);
    if (seen.has(alias)) continue;
    seen.add(alias);
    parts.push(`${v.colorAggregationExp} AS ${alias}`);
  }
  return parts.join(', ');
}

export function fieldType(kind: string): string {
  return { number: 'real', string: 'string', boolean: 'boolean', timestamp: 'timestamp' }[kind] ?? 'string';
}
```

```ts
// h3ColorDomain fixes the colour domain of an aggregated H3 layer from the per-cell values at the current
// display resolution (CARTO stores the same thing as visConfig.colorAggregationDomain).
export async function h3ColorDomain({ dataset, expression, scale, steps, viewport, ctx, fetcher = fetch }: H3DomainRequest): Promise<number[] | null> {
  const tileUrl = new URL(dataset.data.tiles[0].replace('{i}', '0'));
  const level = Number(tileUrl.searchParams.get('aggregationResLevel') ?? 4);
  const dataRes = (dataset.data.maxresolution ?? 15 - level) + level;
  const res = Math.min(dataRes, _getHexagonResolution(viewport, TILE_SIZE) + level);
  const col = quoteIdent(getColumnNameFromGeoColumn(dataset.geoColumn) ?? 'h3');
  const from = dataset.type === 'table' ? quoteIdent(dataset.source) : `(${dataset.source})`;
  const q = `SELECT h3_cell_to_parent(${col}, ${res}) AS __cell, ${expression} AS __value FROM ${from} AS __q GROUP BY 1`;
  const params = new URLSearchParams({ q });
  if (dataset.queryParameters) params.set('queryParameters', JSON.stringify(dataset.queryParameters));
  const res2 = await fetcher(`${ctx.apiBaseUrl}/v3/stats/${dataset.connectionName ?? 'osm'}/__value?${params}`, {
    headers: { Authorization: `Bearer ${ctx.accessToken}` },
  });
  if (!res2.ok) throw new Error(`stats failed: ${res2.status}`);
  const s = (await res2.json()) as { min?: number; max?: number; quantiles?: Record<string, number[]> };
  if (s.min === undefined || s.min === null) return null;
  if (scale === 'quantile' && s.quantiles?.[String(steps)]) return s.quantiles[String(steps)];
  return [s.min, s.max ?? s.min];
}
```

  - New workspace client functions:
    - `patchMap(id, body, f?)`
    - `saveDataset(mapId, doc, f?)`: POST, which upserts by id (server M1 behaviour)
    - `deleteDataset(mapId, dsId, f?)`: a 404 is ignored
    - `listResources(conn, f?)`

Derived fields (spec D5, D6) are recomputed by the reducer after every action:
- For every `h3:` dataset, `aggregationExp` comes from `buildAggregationExp`.
- For every dataset with a `queryTemplate`, `source` and `queryParameters` are compiled from it. A compile error goes into `errors[id]` and the last good `source` is kept.
- For `tileset` datasets, `columns` is the set of fields their layers' channels and popups reference.

A dataset whose derived fields change gets its `rev` bumped, which is what autosave saves.

```ts
import type { Filters } from '@carto/api-client';
import { buildAggregationExp } from '../lib/aggregation';
import type { DatasetDoc, LayerDoc, MapConfig, MapDoc, MapState, SqlParameter, WidgetDoc } from '../lib/mapDoc';
import { normalizeConfig } from '../lib/defaults';
import { compileQuery } from '../lib/sqlParams';

export interface BuilderState {
  map: MapDoc;
  datasets: DatasetDoc[];
  errors: Record<string, string>;
  rev: { map: number; datasets: Record<string, number> };
  saved: { map: number; datasets: Record<string, number> };
  deleted: string[];
}

export type Action =
  | { type: 'renameMap'; title: string }
  | { type: 'setMapState'; mapState: MapState }
  | { type: 'setBasemap'; styleId: string }
  | { type: 'addDataset'; dataset: DatasetDoc }
  | { type: 'updateDataset'; id: string; patch: Partial<DatasetDoc> }
  | { type: 'removeDataset'; id: string }
  | { type: 'addLayer'; layer: LayerDoc }
  | { type: 'updateLayer'; id: string; update: (l: LayerDoc) => LayerDoc }
  | { type: 'removeLayer'; id: string }
  | { type: 'moveLayer'; id: string; delta: -1 | 1 }
  | { type: 'setPopupFields'; layerId: string; fields: string[] }
  | { type: 'addWidget'; widget: WidgetDoc }
  | { type: 'updateWidget'; id: string; patch: Partial<WidgetDoc> }
  | { type: 'removeWidget'; id: string }
  | { type: 'setFilters'; datasetId: string; filters: Filters }
  | { type: 'addSqlParameter'; param: SqlParameter }
  | { type: 'updateSqlParameter'; param: SqlParameter }
  | { type: 'removeSqlParameter'; id: string }
  | { type: 'saved'; map: number; datasets: Record<string, number>; deleted: string[] };

export function initState(map: MapDoc, datasets: DatasetDoc[]): BuilderState {
  const s: BuilderState = {
    map: { ...map, keplerMapConfig: normalizeConfig(map.keplerMapConfig) },
    datasets,
    errors: {},
    rev: { map: 0, datasets: {} },
    saved: { map: 0, datasets: {} },
    deleted: [],
  };
  const derived = derive(s);
  // what was loaded is what the server has: derived changes on load are saved with the first edit
  return { ...derived, saved: { map: 0, datasets: { ...derived.rev.datasets } } };
}

export const hasChanges = (s: BuilderState) => s.rev.map > s.saved.map || s.deleted.length > 0 || dirtyDatasets(s).length > 0;

export const dirtyDatasets = (s: BuilderState) => s.datasets.filter((d) => (s.rev.datasets[d.id] ?? 0) > (s.saved.datasets[d.id] ?? 0));

function editConfig(s: BuilderState, edit: (c: MapConfig) => MapConfig): BuilderState {
  const config = edit(s.map.keplerMapConfig.config);
  return { ...s, map: { ...s.map, keplerMapConfig: { ...s.map.keplerMapConfig, config } }, rev: { ...s.rev, map: s.rev.map + 1 } };
}

const editLayers = (s: BuilderState, edit: (ls: LayerDoc[]) => LayerDoc[]) =>
  editConfig(s, (c) => ({ ...c, visState: { ...c.visState, layers: edit(c.visState.layers) } }));

function bumpDataset(s: BuilderState, id: string): BuilderState {
  return { ...s, rev: { ...s.rev, datasets: { ...s.rev.datasets, [id]: (s.rev.datasets[id] ?? 0) + 1 } } };
}

function withoutOwner(filters: Filters, owner: string): Filters {
  const out: Filters = {};
  for (const [col, byType] of Object.entries(filters)) {
    const kept = Object.fromEntries(Object.entries(byType).filter(([, f]) => (f as { owner?: string })?.owner !== owner));
    if (Object.keys(kept).length) out[col] = kept as Filters[string];
  }
  return out;
}

function reduce(s: BuilderState, a: Action): BuilderState {
  switch (a.type) {
    case 'renameMap':
      return { ...s, map: { ...s.map, title: a.title }, rev: { ...s.rev, map: s.rev.map + 1 } };
    case 'setMapState':
      return editConfig(s, (c) => ({ ...c, mapState: { ...c.mapState, ...a.mapState } }));
    case 'setBasemap':
      return editConfig(s, (c) => ({ ...c, basemapConfig: { styleId: a.styleId }, mapStyle: { ...c.mapStyle, styleType: a.styleId } }));
    case 'addDataset':
      return bumpDataset({ ...s, datasets: [...s.datasets, a.dataset], deleted: s.deleted.filter((id) => id !== a.dataset.id) }, a.dataset.id);
    case 'updateDataset':
      return bumpDataset({ ...s, datasets: s.datasets.map((d) => (d.id === a.id ? { ...d, ...a.patch, id: d.id } : d)) }, a.id);
    case 'removeDataset': {
      const next = editConfig(s, (c) => {
        const { [a.id]: _gone, ...filters } = c.filters;
        return {
          ...c,
          filters,
          visState: { ...c.visState, layers: c.visState.layers.filter((l) => l.config.dataId !== a.id) },
          widgets: c.widgets.filter((w) => w.dataSource !== a.id),
        };
      });
      const { [a.id]: _e, ...errors } = next.errors;
      return { ...next, errors, datasets: next.datasets.filter((d) => d.id !== a.id), deleted: [...next.deleted, a.id] };
    }
    case 'addLayer':
      return editLayers(s, (ls) => [a.layer, ...ls]); // kepler order: index 0 is the top layer
    case 'updateLayer':
      return editLayers(s, (ls) => ls.map((l) => (l.id === a.id ? a.update(l) : l)));
    case 'removeLayer': {
      const next = editLayers(s, (ls) => ls.filter((l) => l.id !== a.id));
      return editConfig(next, (c) => {
        const { [a.id]: _p, ...layers } = c.popupSettings.layers;
        return { ...c, popupSettings: { layers } };
      });
    }
    case 'moveLayer':
      return editLayers(s, (ls) => {
        const i = ls.findIndex((l) => l.id === a.id);
        const j = i + a.delta;
        if (i < 0 || j < 0 || j >= ls.length) return ls;
        const out = [...ls];
        [out[i], out[j]] = [out[j], out[i]];
        return out;
      });
    case 'setPopupFields':
      return editConfig(s, (c) => ({
        ...c,
        popupSettings: { layers: { ...c.popupSettings.layers, [a.layerId]: { click: { fields: a.fields.map((name) => ({ name })) } } } },
      }));
    case 'addWidget':
      return editConfig(s, (c) => ({ ...c, widgets: [...c.widgets, a.widget] }));
    case 'updateWidget':
      return editConfig(s, (c) => ({ ...c, widgets: c.widgets.map((w) => (w.id === a.id ? { ...w, ...a.patch, id: w.id } : w)) }));
    case 'removeWidget':
      return editConfig(s, (c) => ({
        ...c,
        widgets: c.widgets.filter((w) => w.id !== a.id),
        filters: Object.fromEntries(Object.entries(c.filters).map(([ds, f]) => [ds, withoutOwner(f, a.id)])),
      }));
    case 'setFilters':
      return editConfig(s, (c) => ({ ...c, filters: { ...c.filters, [a.datasetId]: a.filters } }));
    case 'addSqlParameter':
      return editConfig(s, (c) => ({ ...c, sqlParameters: [...c.sqlParameters, a.param] }));
    case 'updateSqlParameter':
      return editConfig(s, (c) => ({ ...c, sqlParameters: c.sqlParameters.map((p) => (p.id === a.param.id ? a.param : p)) }));
    case 'removeSqlParameter':
      return editConfig(s, (c) => ({ ...c, sqlParameters: c.sqlParameters.filter((p) => p.id !== a.id) }));
    case 'saved':
      return {
        ...s,
        saved: { map: Math.max(s.saved.map, a.map), datasets: { ...s.saved.datasets, ...a.datasets } },
        deleted: s.deleted.filter((id) => !a.deleted.includes(id)),
      };
  }
}

// columnsFor lists the fields a tileset dataset must put in its tiles: styled channels and popup fields.
function columnsFor(datasetId: string, c: MapConfig): string[] {
  const cols = new Set<string>();
  for (const l of c.visState.layers) {
    if (l.config.dataId !== datasetId) continue;
    const ch = l.visualChannels;
    for (const f of [ch.colorField, ch.strokeColorField, ch.sizeField, ch.radiusField]) if (f) cols.add(f.name);
    for (const f of c.popupSettings.layers[l.id]?.click?.fields ?? []) cols.add(f.name);
  }
  return [...cols].sort();
}

// derive recomputes compiled SQL, H3 aggregationExp and tile columns; changed datasets get their rev bumped.
function derive(s: BuilderState): BuilderState {
  const c = s.map.keplerMapConfig.config;
  const errors = { ...s.errors };
  let out = s;
  const datasets = s.datasets.map((d) => {
    const next = { ...d };
    if (d.queryTemplate) {
      try {
        Object.assign(next, compileQuery(d.queryTemplate, c.sqlParameters));
        delete errors[d.id];
      } catch (e) {
        errors[d.id] = (e as Error).message;
      }
    }
    if (d.geoColumn.startsWith('h3:')) next.aggregationExp = buildAggregationExp(d.id, c.visState.layers);
    else next.columns = columnsFor(d.id, c);
    if (JSON.stringify(next) !== JSON.stringify(d)) out = bumpDataset(out, d.id);
    return next;
  });
  return { ...out, datasets, errors };
}

export function builderReducer(s: BuilderState, a: Action): BuilderState {
  const next = reduce(s, a);
  return a.type === 'saved' ? next : derive(next);
}
```

```ts
import { useEffect, useRef, useState, type Dispatch } from 'react';
import type { DatasetDoc, MapDoc } from '../lib/mapDoc';
import { dirtyDatasets, hasChanges, type Action, type BuilderState } from './state';

export interface SaveApi {
  patchMap(id: string, body: Pick<MapDoc, 'title' | 'keplerMapConfig'>): Promise<unknown>;
  saveDataset(mapId: string, doc: DatasetDoc): Promise<unknown>;
  deleteDataset(mapId: string, datasetId: string): Promise<unknown>;
}

export type SaveStatus = 'idle' | 'saving' | 'saved' | 'error';

// useAutosave saves delayMs after the last change, never runs two saves at once, and acknowledges
// only the revisions it sent, so edits made during a save are saved by the next round.
export function useAutosave(state: BuilderState, dispatch: Dispatch<Action>, api: SaveApi, delayMs = 800): SaveStatus {
  const [status, setStatus] = useState<SaveStatus>('idle');
  const latest = useRef(state);
  latest.current = state;
  const inFlight = useRef(false);
  const timer = useRef<ReturnType<typeof setTimeout> | undefined>(undefined);
  const apiRef = useRef(api);
  apiRef.current = api;

  const schedule = useRef<() => void>(() => {});
  schedule.current = () => {
    clearTimeout(timer.current);
    timer.current = setTimeout(run, delayMs);
  };

  async function run() {
    if (inFlight.current) {
      schedule.current();
      return;
    }
    const s = latest.current;
    if (!hasChanges(s)) return;
    inFlight.current = true;
    setStatus('saving');
    const mapRev = s.rev.map;
    const datasets = dirtyDatasets(s);
    const revs = Object.fromEntries(datasets.map((d) => [d.id, s.rev.datasets[d.id] ?? 0]));
    const deleted = [...s.deleted];
    try {
      if (mapRev > s.saved.map) await apiRef.current.patchMap(s.map.id, { title: s.map.title, keplerMapConfig: s.map.keplerMapConfig });
      for (const d of datasets) await apiRef.current.saveDataset(s.map.id, d);
      for (const id of deleted) await apiRef.current.deleteDataset(s.map.id, id);
      dispatch({ type: 'saved', map: mapRev, datasets: revs, deleted });
      setStatus('saved');
    } catch {
      setStatus('error');
    } finally {
      inFlight.current = false;
    }
  }

  useEffect(() => {
    if (hasChanges(state)) schedule.current();
  }, [state]);

  useEffect(() => () => clearTimeout(timer.current), []);

  return status;
}
```

```ts
import type { Layer } from '@deck.gl/core';
import { useEffect, useMemo, useState } from 'react';
import { prepareMap, type PreparedMap, type RenderContext } from '../map/prepareMap';
import { toDeckLayers } from '../map/toDeckLayers';
import type { BuilderState } from './state';

// useRenderedMap re-runs the CARTO pipeline when anything that affects rendering changes (not on pan/zoom).
export function useRenderedMap(state: BuilderState, ctx: RenderContext, delayMs = 300) {
  const [out, setOut] = useState<{ prepared: PreparedMap | null; layers: Layer[]; error: string | null }>({ prepared: null, layers: [], error: null });
  const c = state.map.keplerMapConfig.config;
  const datasets = useMemo(() => state.datasets.filter((d) => !state.errors[d.id]), [state.datasets, state.errors]);
  const key = JSON.stringify([c.visState.layers, c.filters, c.popupSettings, datasets]);

  useEffect(() => {
    let cancelled = false;
    const t = setTimeout(() => {
      prepareMap(state.map, datasets, ctx).then(
        (prepared) => !cancelled && setOut({ prepared, layers: toDeckLayers(prepared.parsed.layers), error: null }),
        (e: Error) => !cancelled && setOut((o) => ({ ...o, error: e.message })),
      );
    }, delayMs);
    return () => {
      cancelled = true;
      clearTimeout(t);
    };
    // key captures everything rendering depends on
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [key]);

  return out;
}
```

```ts
import type { RGB } from './mapDoc';

export const rgbToHex = ([r, g, b]: RGB) => '#' + [r, g, b].map((v) => Math.round(v).toString(16).padStart(2, '0')).join('');

export function hexToRgb(hex: string): RGB {
  let h = hex.replace('#', '');
  if (h.length === 3) h = [...h].map((c) => c + c).join('');
  const n = parseInt(h, 16);
  return [(n >> 16) & 255, (n >> 8) & 255, n & 255];
}
```

`web/src/builder/LayersPanel.tsx`:

```tsx
import { getColumnNameFromGeoColumn } from '@carto/api-client';
import { useState, type Dispatch } from 'react';
import { clearColorBy, h3Expression, setColumnColorBy, setH3ColorBy } from '../lib/aggregation';
import { hexToRgb, rgbToHex } from '../lib/color';
import { newLayer, PALETTES } from '../lib/defaults';
import { h3ColorDomain } from '../lib/h3Domain';
import type { DatasetDoc, LayerDoc, MapConfig, Operation, ScaleType } from '../lib/mapDoc';
import type { Viewport } from '../map/MapView';
import type { LoadedDataset, RenderContext } from '../map/prepareMap';
import type { Action } from './state';

const OPS: Operation[] = ['sum', 'avg', 'min', 'max'];

export function parseH3Expression(exp: string | null): { op: Operation; column?: string } | null {
  if (!exp) return null;
  if (exp === 'count(*)') return { op: 'count' };
  const m = exp.match(/^(sum|avg|min|max)\("((?:[^"]|"")*)"\)$/);
  return m ? { op: m[1] as Operation, column: m[2].replaceAll('""', '"') } : null;
}

export interface LayersPanelProps {
  layers: LayerDoc[];
  datasets: DatasetDoc[];
  loaded: LoadedDataset[];
  popupSettings: MapConfig['popupSettings'];
  dispatch: Dispatch<Action>;
  viewport: Viewport | null;
  ctx: RenderContext;
  fetcher?: typeof fetch;
}

export function LayersPanel({ layers, datasets, loaded, popupSettings, dispatch, viewport, ctx, fetcher = fetch }: LayersPanelProps) {
  const [newSource, setNewSource] = useState('');
  return (
    <section className="panel">
      <h2>Layers</h2>
      <ul className="panel-list">
        {layers.map((layer, i) => (
          <LayerItem
            key={layer.id}
            layer={layer}
            dataset={loaded.find((d) => d.id === layer.config.dataId)}
            popupFields={(popupSettings.layers[layer.id]?.click?.fields ?? []).map((f) => f.name)}
            isFirst={i === 0}
            isLast={i === layers.length - 1}
            dispatch={dispatch}
            viewport={viewport}
            ctx={ctx}
            fetcher={fetcher}
          />
        ))}
      </ul>
      <div className="row">
        <select aria-label="New layer source" value={newSource} onChange={(e) => setNewSource(e.target.value)}>
          <option value="">Choose a source…</option>
          {datasets.map((d) => (
            <option key={d.id} value={d.id}>{d.label}</option>
          ))}
        </select>
        <button
          disabled={!newSource}
          onClick={() => {
            const ds = datasets.find((d) => d.id === newSource)!;
            dispatch({ type: 'addLayer', layer: newLayer(ds.geoColumn.startsWith('h3:') ? 'h3' : 'tileset', ds, layers.length) });
          }}
        >
          Add layer
        </button>
      </div>
      <p className="credit">Colors: CARTOColors (CC BY 4.0)</p>
    </section>
  );
}

interface LayerItemProps {
  layer: LayerDoc;
  dataset?: LoadedDataset;
  popupFields: string[];
  isFirst: boolean;
  isLast: boolean;
  dispatch: Dispatch<Action>;
  viewport: Viewport | null;
  ctx: RenderContext;
  fetcher: typeof fetch;
}

function LayerItem({ layer, dataset, popupFields, isFirst, isLast, dispatch, viewport, ctx, fetcher }: LayerItemProps) {
  const [error, setError] = useState<string | null>(null);
  const label = layer.config.label;
  const vis = layer.config.visConfig;
  const vc = layer.visualChannels;
  const update = (fn: (l: LayerDoc) => LayerDoc) => dispatch({ type: 'updateLayer', id: layer.id, update: fn });
  const spatial = dataset ? getColumnNameFromGeoColumn(dataset.geoColumn) : null;
  const fields = (dataset?.data.schema ?? []).filter((c) => c.name !== spatial && c.type !== 'geometry' && c.name !== '_carto_feature_id');
  const numeric = fields.filter((f) => f.type === 'number');
  const isH3 = layer.type === 'h3';
  const h3 = isH3 ? parseH3Expression(vis.colorAggregationExp) : null;
  const colorValue = isH3 ? (h3 ? `${h3.op}:${h3.column ?? ''}` : '') : (vc.colorField?.name ?? '');
  const palette = vis.colorRange.name;
  const steps = vis.colorRange.colors.length;

  async function restyle(next: { value?: string; palette?: string; scale?: ScaleType; steps?: number }) {
    const value = next.value ?? colorValue;
    const pal = next.palette ?? palette;
    const st = next.steps ?? steps;
    setError(null);
    if (!value) {
      update(clearColorBy);
      return;
    }
    if (!isH3) {
      const field = fields.find((f) => f.name === value)!;
      const scale: ScaleType = field.type === 'string' ? 'ordinal' : next.scale ?? (vc.colorScale === 'ordinal' ? 'quantize' : vc.colorScale);
      const p = field.type === 'string' && !next.palette && vc.colorField?.name !== value ? 'Bold' : pal;
      update((l) => setColumnColorBy(l, { name: field.name, kind: field.type }, scale, p, st));
      return;
    }
    const [op, column] = value.split(':') as [Operation, string];
    const scale: ScaleType = next.scale ?? (vc.colorScale === 'ordinal' ? 'quantize' : vc.colorScale);
    const expression = h3Expression(op, column || undefined);
    let domain: number[] | null = null;
    if (dataset && viewport) {
      try {
        domain = await h3ColorDomain({ dataset, expression, scale, steps: st, viewport, ctx, fetcher });
      } catch (e) {
        setError((e as Error).message);
      }
    }
    update((l) => setH3ColorBy(l, op, column || undefined, scale, pal, st, domain));
  }

  return (
    <li>
      <div className="row">
        <label>
          <input
            type="checkbox"
            aria-label={`Show ${label}`}
            checked={layer.config.isVisible}
            onChange={(e) => update((l) => ({ ...l, config: { ...l.config, isVisible: e.target.checked } }))}
          />{' '}
          <input aria-label={`Name of ${label}`} value={label} onChange={(e) => update((l) => ({ ...l, config: { ...l.config, label: e.target.value } }))} />
        </label>
        <span>
          <button aria-label={`Move ${label} up`} disabled={isFirst} onClick={() => dispatch({ type: 'moveLayer', id: layer.id, delta: -1 })}>↑</button>
          <button aria-label={`Move ${label} down`} disabled={isLast} onClick={() => dispatch({ type: 'moveLayer', id: layer.id, delta: 1 })}>↓</button>
          <button aria-label={`Remove ${label}`} onClick={() => dispatch({ type: 'removeLayer', id: layer.id })}>✕</button>
        </span>
      </div>
      <div className="row">
        <label>
          Fill{' '}
          <input
            type="color"
            aria-label={`Fill color of ${label}`}
            value={rgbToHex(layer.config.color)}
            onChange={(e) => update((l) => ({ ...l, config: { ...l.config, color: hexToRgb(e.target.value) } }))}
          />
        </label>
        <label>
          Opacity{' '}
          <input
            type="range" min={0} max={1} step={0.05} aria-label={`Opacity of ${label}`} value={vis.opacity}
            onChange={(e) => update((l) => ({ ...l, config: { ...l.config, visConfig: { ...l.config.visConfig, opacity: Number(e.target.value) } } }))}
          />
        </label>
        {!isH3 && (
          <label>
            Radius{' '}
            <input
              type="number" min={1} max={50} aria-label={`Radius of ${label}`} value={vis.radius}
              onChange={(e) => update((l) => ({ ...l, config: { ...l.config, visConfig: { ...l.config.visConfig, radius: Number(e.target.value) } } }))}
            />
          </label>
        )}
      </div>
      <label>
        Color based on{' '}
        <select aria-label={`Color ${label} by`} value={colorValue} onChange={(e) => restyle({ value: e.target.value })}>
          <option value="">None (single color)</option>
          {isH3 ? (
            <>
              <option value="count:">Count of rows</option>
              {numeric.flatMap((f) => OPS.map((op) => <option key={`${op}:${f.name}`} value={`${op}:${f.name}`}>{`${op} of ${f.name}`}</option>))}
            </>
          ) : (
            fields.map((f) => <option key={f.name} value={f.name}>{f.name}</option>)
          )}
        </select>
      </label>
      {colorValue && (
        <div className="row">
          <select aria-label={`Palette of ${label}`} value={palette} onChange={(e) => restyle({ palette: e.target.value })}>
            {PALETTES.map((p) => <option key={p} value={p}>{p}</option>)}
          </select>
          {vc.colorScale !== 'ordinal' && (
            <select aria-label={`Scale of ${label}`} value={vc.colorScale} onChange={(e) => restyle({ scale: e.target.value as ScaleType })}>
              <option value="quantize">Equal intervals</option>
              <option value="quantile">Quantiles</option>
            </select>
          )}
          <select aria-label={`Steps of ${label}`} value={steps} onChange={(e) => restyle({ steps: Number(e.target.value) })}>
            {[3, 4, 5, 6, 7].map((n) => <option key={n} value={n}>{n} steps</option>)}
          </select>
        </div>
      )}
      {error && <p role="alert" className="error">{error}</p>}
      {fields.length > 0 && (
        <details>
          <summary>Popup fields</summary>
          {fields.map((f) => (
            <label key={f.name}>
              <input
                type="checkbox"
                aria-label={`Popup: ${f.name}`}
                checked={popupFields.includes(f.name)}
                onChange={(e) =>
                  dispatch({ type: 'setPopupFields', layerId: layer.id, fields: e.target.checked ? [...popupFields, f.name] : popupFields.filter((n) => n !== f.name) })
                }
              />{' '}
              {f.name}
            </label>
          ))}
        </details>
      )}
    </li>
  );
}
```

For H3 layers, popup fields list the source columns; a picked cell shows whichever of them its tile carries (`__aggregationValue` and colour aliases come from `aggregationExp`).

```ts
export function useViewportFilter(viewport: Viewport | null, delayMs = 300): SpatialFilter | undefined {
  const [filter, setFilter] = useState<SpatialFilter | undefined>(undefined);
  const key = viewport ? [viewport.west, viewport.south, viewport.east, viewport.north].map((v) => v.toFixed(5)).join(',') : '';
  useEffect(() => {
    if (!viewport) return;
    const t = setTimeout(() => setFilter(createViewportSpatialFilter([viewport.west, viewport.south, viewport.east, viewport.north])), delayMs);
    return () => clearTimeout(t);
    // the key is the viewport bounds
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [key]);
  return filter;
}
```

```tsx
import { useEffect, useState } from 'react';

type Opts = { filters: Filters; filterOwner: string; spatialFilter?: SpatialFilter };
type Category = { name: string | null; value: number };
export type WidgetData =
  | { kind: 'formula'; value: number | null }
  | { kind: 'category'; rows: Category[] }
  | { kind: 'histogram'; ticks: number[]; values: number[] }
  | { kind: 'range'; min: number | null; max: number | null }
  | { kind: 'table'; rows: Record<string, unknown>[]; total: number }
  | { kind: 'timeseries'; rows: { name: number; value: number }[] };

export function equalTicks(min: number, max: number, buckets: number): number[] {
  if (!(max > min)) return [];
  return Array.from({ length: buckets - 1 }, (_, i) => +(min + ((i + 1) * (max - min)) / buckets).toPrecision(12));
}

export async function loadWidget(w: WidgetDoc, ws: WidgetSource, opts: Opts): Promise<WidgetData> {
  switch (w.type) {
    case 'formula': {
      const r = await ws.getFormula({ ...opts, column: w.operation === 'count' ? '*' : w.column, operation: w.operation });
      return { kind: 'formula', value: r.value ?? null };
    }
    case 'category': {
      const rows = await ws.getCategories({ ...opts, column: w.column, operation: w.operation, operationColumn: w.operationColumn ?? w.column });
      return { kind: 'category', rows: rows as Category[] };
    }
    case 'histogram': {
      const r = await ws.getRange({ ...opts, column: w.column });
      const ticks = w.ticks ?? equalTicks(r.min, r.max, 10);
      if (!ticks.length) return { kind: 'histogram', ticks, values: [] };
      const values = await ws.getHistogram({ ...opts, column: w.column, operation: 'count', ticks });
      return { kind: 'histogram', ticks, values };
    }
    case 'range': {
      const r = await ws.getRange({ ...opts, column: w.column });
      return { kind: 'range', min: r.min ?? null, max: r.max ?? null };
    }
    case 'table': {
      const r = await ws.getTable({ ...opts, columns: w.columns ?? [w.column], limit: 10 });
      return { kind: 'table', rows: r.rows as Record<string, unknown>[], total: r.totalCount };
    }
    case 'timeseries': {
      const r = await ws.getTimeSeries({ ...opts, column: w.column, stepSize: w.stepSize ?? 'day', operation: w.operation, operationColumn: w.operationColumn ?? w.column });
      return { kind: 'timeseries', rows: r.rows as { name: number; value: number }[] };
    }
  }
}

export function toggleCategory(filters: Filters, w: WidgetDoc, name: string): Filters {
  const next = structuredClone(filters);
  const mine = next[w.column]?.[FilterType.IN];
  const current = (mine?.owner === w.id ? (mine.values as string[]) : []) ?? [];
  const values = current.includes(name) ? current.filter((v) => v !== name) : [...current, name];
  removeFilter(next, { column: w.column, owner: w.id });
  if (values.length) addFilter(next, { column: w.column, type: FilterType.IN, values, owner: w.id });
  return next;
}

  widget: WidgetDoc;
  dataset?: LoadedDataset;

export function Widget({ widget, dataset, filters, spatialFilter, onFilter }: WidgetProps) {
  const [data, setData] = useState<WidgetData | null>(null);
  const [error, setError] = useState<string | null>(null);
  const key = JSON.stringify([widget, filters, spatialFilter, dataset?.data.tiles?.[0]]);

  useEffect(() => {
    if (!dataset) return;
    let cancelled = false;
    loadWidget(widget, dataset.data.widgetSource, { filters, filterOwner: widget.id, spatialFilter }).then(
      (d) => {
        if (cancelled) return;
        setData(d);
        setError(null);
      },
      (e: Error) => !cancelled && setError(e.message),
    );
    return () => {
      cancelled = true;
    };
    // key captures every input
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [key]);

  if (!dataset) return <p className="muted">Source not loaded</p>;
  if (error) return <p role="alert" className="error">{error}</p>;
  if (!data) return <p className="muted">Loading…</p>;

  switch (data.kind) {
    case 'formula':
      return <p className="formula">{data.value === null ? '–' : fmt.format(data.value)}</p>;
    case 'range':
      return <p className="formula">{data.min === null ? '–' : `${fmt.format(data.min)} – ${fmt.format(data.max ?? data.min)}`}</p>;
    case 'category': {
      const max = Math.max(1, ...data.rows.map((r) => r.value ?? 0));
      const mine = filters[widget.column]?.[FilterType.IN];
      const selected = mine?.owner === widget.id ? (mine.values as string[]) : [];
      return (
        <div>
          <ul className="bars">
            {data.rows.map((r) => {
              const name = r.name ?? 'null';
              return (
                <li key={name}>
                  <button className="bar-row" aria-pressed={selected.includes(name)} onClick={() => onFilter?.(toggleCategory(filters, widget, name))}>
                    <span>{name}</span>
                    <span>{fmt.format(r.value)}</span>
                    <i style={{ width: `${(100 * (r.value ?? 0)) / max}%` }} />
                  </button>
                </li>
              );
            })}
          </ul>
          {selected.length > 0 && <button onClick={() => onFilter?.(clearOwn(filters, widget))}>Clear</button>}
        </div>
      );
    }
    case 'histogram':
    case 'timeseries': {
      const values = data.kind === 'histogram' ? data.values : data.rows.map((r) => r.value);
      const labels = data.kind === 'histogram' ? ['<', ...data.ticks.map((t) => `≥${fmt.format(t)}`)] : data.rows.map((r) => new Date(r.name).toISOString().slice(0, 10));
      const max = Math.max(1, ...values);
      return (
        <ul className="columns" aria-label={widget.title}>
          {values.map((v, i) => (
            <li key={i} title={`${labels[i] ?? ''}: ${fmt.format(v)}`}>
              <i style={{ height: `${(100 * v) / max}%` }} />
            </li>
          ))}
        </ul>
      );
    }
    case 'table':
      return (
        <table className="widget-table">
          <thead>
            <tr>{(widget.columns ?? [widget.column]).map((c) => <th key={c}>{c}</th>)}</tr>
          </thead>
          <tbody>
            {data.rows.map((r, i) => (
              <tr key={i}>{(widget.columns ?? [widget.column]).map((c) => <td key={c}>{String(r[c] ?? '')}</td>)}</tr>
            ))}
          </tbody>
          <caption>{fmt.format(data.total)} rows</caption>
        </table>
      );
  }
}
```

```tsx
export function slugify(name: string): string {
  let s = name.toLowerCase().replace(/[^a-z0-9]+/g, '_').replace(/^_+|_+$/g, '');
  if (!s) return 'param';
  if (/^[0-9]/.test(s)) s = 'p' + s;
  if (s.startsWith('p_')) s = 'param_' + s.replace(/^p_+/, 'p_');
  return s;
}

function usage(p: SqlParameter): string {
  return p.type === 'Category' || p.type === 'Numeric' ? `{{${p.item.sqlName}}}` : `{{${p.start.sqlName}}} … {{${p.end.sqlName}}}`;
}

type Kind = SqlParameter['type'];
```

```tsx
import type { LayerDescriptor } from '@carto/api-client';
import { rgbToHex } from '../lib/color';
import type { LayerDoc } from '../lib/mapDoc';

type Scale = { type: string; domain?: unknown[]; range?: string[] };
const fmt = new Intl.NumberFormat('en-US', { maximumFractionDigits: 2 });

export function legendEntries(layer: LayerDoc, descriptor?: LayerDescriptor) {
  const title = layer.config.label;
  const vis = layer.config.visConfig;
  if (vis.colorAggregation === 'custom' && vis.colorAggregationExp && !vis.colorAggregationDomain) return { title, entries: [], empty: true };
  const scale = (descriptor?.scales as Record<string, Scale> | undefined)?.fillColor;
  if (!scale) return { title, entries: [{ label: title, color: rgbToHex(layer.config.color) }], empty: false };
  const range = scale.range ?? [];
  const domain = scale.domain ?? [];
  if (!range.length || !domain.length) return { title, entries: [], empty: true };
  if (scale.type === 'ordinal') {
    return { title, entries: domain.slice(0, range.length).map((d, i) => ({ label: String(d ?? 'null'), color: range[i] })), empty: false };
  }
  const nums = domain.map(Number);
  const lowers =
    scale.type === 'quantile' && nums.length >= range.length
      ? nums.slice(0, range.length)
      : range.map((_, i) => nums[0] + (i * (nums[nums.length - 1] - nums[0])) / range.length);
  return { title, entries: range.map((color, i) => ({ label: `≥ ${fmt.format(lowers[i])}`, color })), empty: false };
}

export function Legend({ layers, descriptors }: { layers: LayerDoc[]; descriptors: (LayerDescriptor | undefined)[] }) {
  const visible = layers.filter((l) => l.config.isVisible);
  if (!visible.length) return null;
  return (
    <div className="legend" aria-label="Legend">
      {visible.map((l) => {
        const { title, entries, empty } = legendEntries(l, descriptors.find((d) => (d?.props as { id?: string })?.id === l.id));
        return (
          <section key={l.id}>
            <h4>{title}</h4>
            {empty ? (
              <p className="muted">No data</p>
            ) : (
              <ul>
                {entries.map((e, i) => (
                  <li key={i}>
                    <i style={{ background: e.color }} /> {e.label}
                  </li>
                ))}
              </ul>
            )}
          </section>
        );
      })}
    </div>
  );
}
```

```tsx
export function popupRows(object: unknown, fields: string[]): { name: string; value: string }[] {
  const o = (object ?? {}) as { properties?: Record<string, unknown> } & Record<string, unknown>;
```

```tsx
type Loaded = { doc: MapDoc; datasets: DatasetDoc[] };

export async function loadPrivate(id: string): Promise<Loaded> {
  const [doc, datasets] = await Promise.all([getMap(id), getDatasets(id)]);
  return { doc: { ...doc, keplerMapConfig: normalizeConfig(doc.keplerMapConfig) }, datasets };
}

export async function loadPublic(id: string): Promise<Loaded> {
  const { datasets, ...doc } = await getPublicMap(id);
  return { doc: { ...doc, keplerMapConfig: normalizeConfig(doc.keplerMapConfig) }, datasets };
}

// M1/M2 dev auth ignores the token; M3 switches to authMode: 'session'.
export const renderContext = () => ({ apiBaseUrl: window.location.origin, accessToken: 'dev' });

export function ViewerPage({ load }: { load: (id: string) => Promise<Loaded> }) {
  const { id = '' } = useParams();
  const [initial, setInitial] = useState<BuilderState | null>(null);
  const [error, setError] = useState<string | null>(null);
  useEffect(() => {
    let cancelled = false;
    setError(null);
    load(id).then(
      (l) => !cancelled && setInitial(initState(l.doc, l.datasets)),
      (e: Error) => !cancelled && setError(e.message),
    );
    return () => {
      cancelled = true;
    };
  }, [id, load]);
  if (error) return <p role="alert">{error}</p>;
  if (!initial) return <p className="loading">Loading…</p>;
  return <Viewer key={id} initial={initial} />;
}

// Viewer reuses the builder reducer for local interaction (filters, parameter values) but never saves.
function Viewer({ initial }: { initial: BuilderState }) {
  const [state, dispatch] = useReducer(builderReducer, initial);
  const ctx = useMemo(renderContext, []);
  const rendered = useRenderedMap(state, ctx);
  const [viewport, setViewport] = useState<Viewport | null>(null);
  const spatialFilter = useViewportFilter(viewport);
  const c = state.map.keplerMapConfig.config;
  const showParams = c.mapSettings.sqlParameterControls && c.sqlParameters.length > 0;
  return (
    <div className="viewer">
      <header>
        <h1>{state.map.title}</h1>
      </header>
      <div className="viewer-body">
        {showParams && (
          <aside className="viewer-side">
            <ParamControls params={c.sqlParameters} onChange={(param) => dispatch({ type: 'updateSqlParameter', param })} />
          </aside>
        )}
        <MapSurface config={c} layers={rendered.layers} descriptors={rendered.prepared?.parsed.layers ?? []} onViewportChange={setViewport} />
        {c.widgets.length > 0 && (
          <aside className="viewer-side">
            <WidgetsColumn
              widgets={c.widgets}
              datasets={rendered.prepared?.datasets ?? []}
              filters={c.filters}
              spatialFilter={spatialFilter}
              onFilter={(datasetId, filters) => dispatch({ type: 'setFilters', datasetId, filters })}
            />
          </aside>
        )}
      </div>
    </div>
  );
}
```
